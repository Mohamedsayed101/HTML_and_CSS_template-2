# Kasper | Template Two

A modern and responsive one-page web template built with **HTML5, CSS3, and Vanilla JavaScript**.  
Kasper is designed for agencies, portfolios, or personal projects with interactive sections and smooth animations.

---

## 🚀 Features

- Fully responsive design using **Flexbox** and **CSS Grid**.  
- Smooth scroll navigation.  
- Mobile-friendly hamburger menu.  
- Landing section with image slider and navigation bullets.  
- Portfolio with filterable categories and "Load More" functionality.  
- Skills section with animated progress bars.  
- Stats section with animated numbers.  
- Pricing plans section.  
- Video, About, Quote, Subscribe, and Contact sections.  
- Back-to-top button for easy navigation.

## 🛠️ Technologies Used

- **HTML5** – Website structure  
- **CSS3** – Styling, animations, media queries  
- **JavaScript (Vanilla)** – Interactive behaviors (slider, portfolio filter, skills animation, stats)  
- **Font Awesome** – Icons  
- **Google Fonts** – Open Sans  

---

## 📱 Responsive Design

- **Desktop**: Full layout with all sections visible.  
- **Tablet & Mobile**: Adjusted grids, hamburger menu, hidden image columns if needed.  
- Smooth animations and section transitions on all devices.
